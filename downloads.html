Windows versions

The Windows version is a ready-to-run folder with LITHOS.exe. No installation needed.

  1. Download the zip of the version you want.
  2. Right-click it and choose Extract All… (do not run it from inside the zip).
  3. Open the folder and double-click LITHOS.exe.

⚠️ Windows may say "Windows protected your PC" because this is a new indie game. Click More info → Run anyway. SmartScreen flags any program that few people have downloaded yet.
