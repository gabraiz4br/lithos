Save tool

move your progress

Your progress (fragments, Laboratory upgrades, achievements, high score and settings) lives in your browser. All versions played on this website share it. Use this page to copy it to another browser or device, or to import a save code.

Old versions have no Save menu, so this is the way to export from them. Play them on this website, then come here. Games on itch.io keep their own separate save: from v0.5 use Settings → Save data inside the game.

Slots 2 and 3 exist from v0.6. Older versions only have slot 1.

1. Export

No save found in this browser yet. Play a version on this site first.

2. Import

Paste a save code (or the contents of a save file) here. This replaces the save in this browser.

Then, in the game

  • To use the code in another place: open v0.5 or later, go to Settings → Save data → Import save and press Ctrl+V.
  • To bring a save from v0.5 into this site: in the game go to Settings → Save data → Copy save code, then paste it in box 2 above.
