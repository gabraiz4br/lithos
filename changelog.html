Changelog

what changed in each version

v0.6 – Save slots and The Veins

The biggest structural update so far. You can keep up to three separate saves, and the cards now have their own unlock tree: The Veins.

  • Pick one of 3 saves when the game opens, start a new game, or delete a save (with double confirmation)
  • Each save has its own fragments, Laboratory, achievements and records. Volume, language and the other settings are shared
  • Your old save becomes Save 1 automatically, nothing is lost
  • Press ESC or Q in the main menu to go back to the save screen
  • Save export and import now works on the save you have open
  • New menu: The Veins, a tree with all 23 cards in 5 veins (Cannon, Hull, Crystal, Orbit and Core)
  • Common cards are always available. Rare, epic and legendary cards must be unlocked with fragments, one node after another (40, 120 and 300 fragments)
  • At the end of each vein you choose 1 of 2 evolutions for 400 fragments, small permanent bonuses such as +1 laser per shot, +1 shield per wave or +1 drone
  • Drag the map with the mouse, or use the arrow keys and Enter
  • Press R twice to refund everything you spent in the tree and try another plan
  • Each save has its own tree. Saves from before v0.6 start with every card already unlocked

v0.5 – Save export and import: take your progress anywhere

The latest version. It adds a way to move your progress between browsers, devices and the Windows version, so you never lose your fragments, upgrades and achievements.

  • New "Save data" menu in Settings: copy a save code, or save it to a file
  • Import it in any version that has the feature (v0.5 or later) to continue where you stopped: fragments, Laboratory upgrades, achievements, high score and settings
  • Works between the browser and the Windows version
  • Saves from older versions can be imported too (use the Save tool page on this site)
  • The code is checked before importing, so a wrong paste does not break your save

v0.4 – Polish and Languages

The biggest polish update. The game speaks four languages, bosses fight in different ways, and the arena finally looks alive.

  • Languages: English, Portuguese, Spanish and French
  • 5 boss attack patterns: rings, aimed fans, spirals, charges and summons
  • Achievement progress bars and an "almost there" alert
  • Locked achievements are now easy to read
  • Rarity-colored card borders: gray, blue, purple and gold
  • Scrollable Laboratory with a reset button (refunds your fragments)
  • God Mode wraps from 99 back to 0, with a reset button
  • Background changes as the waves go on
  • Fixed the bug that let the ship escape the arena
  • Fixed the accuracy stat
  • Tutorial rewritten: asteroid types, the Laboratory and bosses explained separately

v0.3 – Progression

This is where runs started to matter beyond a single game: permanent upgrades, trophies and stats give you a reason to come back.

  • The Laboratory: earn fragments every run and buy permanent upgrades
  • 21 achievements, plus a platinum trophy for unlocking them all
  • Achievements can be viewed in the pause menu too
  • Run stats on the game-over screen
  • Relaxing ambient space music
  • First-run setup for difficulty, followed by the tutorial
  • More settings: particles, health bars, crosshair
  • Choose the start wave in God Mode

v0.2 – Quality of life and secrets

A small update that gave the game its final name, its first music and a hidden surprise for curious players.

  • New title: L.I.T.H.O.S.
  • "NEW" tag on cards you have not picked yet
  • Q works as an extra back key in menus

Beta – First flight

Where it all started: a triangle, a mouse and a lot of rocks. Simple, but the core of the game was already here.

  • Ship with mouse aim and lasers
  • Asteroids in three sizes that split when destroyed
  • Waves that get harder every round
  • Pick 1 of 3 upgrade cards after each wave
  • Walls at the screen edges, plus health bars for the ship and the asteroids
  • Menu, settings and tutorial
  • 320×180 black-and-white pixel art with a custom bitmap font
  • Simple sound effects made in code
